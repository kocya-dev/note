## Storage

- DynamoDB

  - フルマネージドな NoSQL データベース
  - 高速な読み書き性能とスケーラビリティを提供
  - グローバルセカンダリインデックスやストリーム機能をサポート
  - オンデマンドキャパシティ
    - 自動的に読み取りおよび書き込みキャパシティを調整
    - トラフィックの変動に対応したスケーラビリティを提供
  - プロビジョンドキャパシティ
    - あらかじめ設定した読み取りおよび書き込みキャパシティを使用
    - 一定のトラフィックに対して安定したパフォーマンスを提供
  - グローバルテーブル
    - 複数のリージョンでのデータ同期を提供
    - 高可用性と低レイテンシを実現
  - DynamoDB Streams
    - データの変更をリアルタイムでキャプチャ
    - イベント駆動型のアプリケーション開発をサポート
  - DynamoDB Accelerator (DAX)

    - インメモリキャッシュを使用して、読み取り性能を向上
    - ミリ秒単位の応答時間を実現
    - クォーラム(多数決)ベースのキャッシュ更新により、データの整合性を確保
      - 例: 3 ノードの DAX クラスターであれば、2 ノードが最新データを持っていれば整合性が保たれる
      - 書き込みは DAX 経由で DynamoDB に直接行われ、DAX ノードは非同期に更新される
        DynamoDB に直接書き込む場合と比較して、DAX 経由の書き込みはレイテンシが若干増加する可能性がある

  - Auto Scaling
    - DynamoDB の読み取りおよび書き込みキャパシティを自動的に調整
    - トラフィックの変動に対応したスケーラビリティを提供

- Amazon S3

  - オブジェクトストレージサービス
  - 高い耐久性と可用性を提供
  - バージョニング、ライフサイクル管理、イベント通知などの機能をサポート
  - クロスリージョンレプリケーション
    - データを複数のリージョンに自動的にレプリケート
    - 高可用性と災害復旧を実現
  - S3 Select (新規顧客向けには提供終了)
    - S3 バケット内のオブジェクトから必要なデータのみを抽出
    - SQL ライクなクエリを使用してデータをフィルタリング
  - S3 Transfer Acceleration
    - エッジロケーションを使用して、データ転送速度を向上
    - グローバルなユーザーに対して高速なアップロードを提供
  - S3 Intelligent-Tiering
    - オブジェクトのアクセスパターンに基づいて自動的にストレージクラスを変更
    - コスト効率の向上を図る
  - クラスごとの特徴
    S3 Standard：高い耐久性・可用性、頻繁アクセス向け、標準料金
    S3 Intelligent-Tiering：アクセス頻度に応じて自動で最適な階層に移動、コスト最適化
    S3 Standard-IA（Infrequent Access）：低頻度アクセス向け、取り出し時に追加料金
    S3 One Zone-IA：低頻度・単一 AZ 保存、コスト重視・可用性は低い
    S3 Glacier Instant Retrieval：即時取り出し可能なアーカイブ、低コスト
    S3 Glacier Flexible Retrieval：数分～数時間で取り出し、アーカイブ用途
    S3 Glacier Deep Archive：最安、取り出しに 12 時間程度、長期保管向け

- Amazon RDS

  - フルマネージドなリレーショナルデータベースサービス
  - MySQL、PostgreSQL、Oracle、SQL Server、MariaDB などをサポート
  - 自動バックアップ、スナップショット、マルチ AZ 配置などの機能を提供
  - クロスリージョンリードレプリカ
    - 複数リージョンへ読み取りレプリカを配置し DR や読み取り分散に活用（書き込みはプライマリのみ）
  - IAM データベース認証
    - IAM 認証情報を使用して、RDS インスタンスへのアクセスを制御
    - パスワード管理の負担を軽減
  - Amazon Aurora
    - MySQL および PostgreSQL 互換の高性能リレーショナルデータベース
    - 高い可用性とスケーラビリティを提供
    - 自動バックアップ、スナップショット、マルチ AZ 配置などの機能を提供
    - Aurora Serverless
      - 自動的にスケールアップ/ダウンするサーバーレスデータベース
      - コスト効率の向上を図る
    - Amazon Aurora Global Database
      - 複数のリージョンでのデータ同期を提供
      - 高可用性と低レイテンシを実現

- Amazon RDS Proxy
  - フルマネージドなデータベースプロキシサービス
  - アプリケーションの接続管理を簡素化
  - 自動スケーリングやフェイルオーバーをサポート
- Amazon ElastiCache

  - フルマネージドなインメモリキャッシュサービス
  - Redis および Memcached をサポート
  - 高速なデータアクセスと低レイテンシを提供
  - ElastiCache for Redis

    - Redis のフルマネージドサービス
    - データの永続化やレプリケーションをサポート

    ### 通信暗号化（In-Transit Encryption/TLS）

    #### できること

    - TLS による クライアント・サーバー間およびノード間通信の暗号化
    - サーバー認証とクライアント認証（Redis AUTH）
    - 既存クラスターへの暗号化追加（段階的移行対応）
    - 暗号化・非暗号化接続の混在運用（Preferred モード）

    #### 制約・要件

    - **対応バージョン**: Redis OSS 3.2.6/4.0.10 以降、Valkey 7.2 以降
    - **既存変更**: Redis OSS 7.0 以降/Valkey 7.2 以降でのみ可能
    - **ネットワーク**: VPC 内のレプリケーショングループのみ
    - **ノードタイプ**: M1、M2 は非対応
    - **有効化**: `TransitEncryptionEnabled=true` で明示的設定が必要
    - **TLS 要件**: 2026 年 1 月 26 日より TLS 1.2 が最低要件
    - **移行プロセス**: Preferred（混在）→ Required（暗号化のみ）の 2 段階必須

    #### パフォーマンス影響

    - 暗号化・復号化による CPU オーバーヘッド
    - 接続確立時間の増加、スループット若干低下
    - 本番導入前のベンチマーク実施推奨

    #### 接続方法

    - valkey-cli/redis-cli: `--tls` オプション使用
    - stunnel: プロキシ経由で TLS 対応
    - アプリケーション: 各言語の TLS 対応ライブラリ（ssl=True 等）

  - ElastiCache for Memcached
    - Memcached のフルマネージドサービス
    - シンプルなキャッシュソリューションを提供

- Amazon MemoryDB
  - フルマネージドな Redis 互換のインメモリデータベース
  - 高い可用性と耐久性を提供
  - データの永続化やレプリケーションをサポート
- Amazon EFS
  - フルマネージドなファイルストレージサービス
  - NFS プロトコルを使用して、EC2 インスタンスからアクセス可能
  - 高いスループットと低レイテンシを提供
  - 複数の EC2 インスタンスから同時アクセスが可能
  - EFS One Zone
    - 単一のアベイラビリティゾーンでの低コストストレージ
    - 単一 AZ 内で冗長化されるが、AZ 障害には耐えない（マルチ AZ 冗長は Standard）
- Amazon EBS
  - ブロックストレージサービス
  - EC2 インスタンスに対して高性能なストレージを提供
  - 通常は単一の EC2 インスタンスにアタッチ可能。io2 ボリュームのマルチアタッチで複数 Nitro ベース EC2 に同時接続可（制約あり）
  - スナップショット機能を使用してデータのバックアップが可能
- Amazon FSx

  - フルマネージドなファイルシステムサービス
  - Windows ファイルサーバーや Lustre ファイルシステムをサポート
  - 高いパフォーマンスとスケーラビリティを提供

  - Amazon FSx for Windows File Server
    - Windows ネイティブのファイルシステム
    - Active Directory と統合可能
  - Amazon FSx for Lustre
    - 高性能な並列ファイルシステム
    - 大規模なデータ処理や機械学習ワークロードに最適
    - 遅延ロード
      - S3 バケットのデータを必要に応じてオンデマンドでロード
        (必要なデータのみを FSx for Lustre にコピーすることで、ストレージコストを削減)
      - 大規模なデータセットの処理に適している
    - バッチロード
      - S3 バケットのデータを一括でロード
      - データセット全体を FSx for Lustre にコピーすることで、高速なアクセスを実現

- Amazon Keyspaces
  - フルマネージドな Apache Cassandra 互換のデータベースサービス
  - 高い可用性とスケーラビリティを提供
  - データの自動バックアップや復元をサポート
