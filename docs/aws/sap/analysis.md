## Analytics

- Amazon Managed Service for Apache Flink

  - フルマネージドな Apache Flink サービス
  - ストリーミングデータ処理を簡素化
  - AWS の他のサービスとの統合が容易
  - Java、Scala、Python などのプログラミング言語をサポート

- Amazon Redshift

  - フルマネージドなデータウェアハウスサービス
  - 大規模なデータ分析を高速に実行
  - SQL ベースのクエリ言語をサポート
  - データのロード、変換、分析を簡素化
  - Redshift Spectrum を使用して S3 上のデータに直接クエリ可能
  - 同時実行スケーリング
    - 自動的に容量を追加および削除することを可能にする。特に読み取りクエリに適しており、問題となっている複雑な読み取りクエリのユースケースに合致する。

- Amazon Athena

  - フルマネージドなクエリサービス
  - S3 上のデータに対して SQL クエリを実行
  - サーバーレスで、インフラの管理が不要
  - 様々なデータフォーマット（CSV、JSON、Parquet など）をサポート

- Amazon OpenSearch Service

  - フルマネージドな検索および分析サービス
  - Elasticsearch 互換の API を提供
  - データのインデックス作成、検索、分析を簡素化
  - セキュリティ、監視、バックアップなどの機能を提供
  - ノード
    - ホットノード（データノード）
      主に新規データの書き込みや頻繁な検索に使われるノード。EBS やインスタンスストアを利用し、高速なパフォーマンスを提供します。
    - UltraWarm ノード
      主に過去データやアクセス頻度の低いデータの保存・検索用。S3 を活用し、コストを大幅に削減できます。
    - コールドストレージ
      さらにアクセス頻度が低いデータ向け。UltraWarm ノードに一時的にアタッチして検索する仕組みで、最も低コストです。
    - 専用マスターノード
      クラスタ管理専用で、データの保存や検索は行いません。クラスタの安定性向上のために利用されます。
    - OpenSearch Optimized Storage（OR1 インスタンス）
      EBS と S3 を組み合わせた新しいストレージ方式。高い耐久性とパフォーマンスを両立します。

- Amazon QuickSight

  - フルマネージドなビジネスインテリジェンスサービス
  - データの可視化、分析、ダッシュボード作成を簡素化
  - 様々なデータソース（S3、Redshift、RDS など）をサポート

- Amazon Glue

  - フルマネージドな ETL（抽出、変換、ロード）サービス
  - データのカタログ化、変換、ロードを簡素化
  - AWS の他のサービスとの統合が容易
  - スケジュールされたジョブやトリガーによる自動化が可能

- Amazon Kinesis

  - フルマネージドなデータストリーミングサービス
  - リアルタイムでのデータ収集、処理、分析をサポート
  - Kinesis Data Streams、Kinesis Data Analytics などのコンポーネントを提供

- Amazon Data Firehose

  - フルマネージドなデータストリーミングサービス
  - データの収集、変換、保存を簡素化
  - Amazon S3、Amazon Redshift、Amazon OpenSearch Service などへのデータ配信をサポート
  - リアルタイムデータ処理やバッチ処理に対応
  - リアルタイム性の比較
    - Kinesis Data Streams と比べると Firehose は内部でバッファリングしてまとめて配信するため、遅延が大きくなりやすい（数十秒〜数分が目安）。
      ただ 0 秒バッファリングも設定できるため、即時性が必要な場合は 0 秒に設定するのも手。ただし 0 秒にすると Firehose のバッファリングメリットがなくなり、コスト高になる可能性がある。
    - ミリ秒〜秒単位の即時性が必要なら Kinesis Data Streams（+ Enhanced Fan-Out）を検討。ログ集約や S3/Redshift への定期配信で運用を簡素化したい場合は Firehose が手軽。

- - Amazon Kinesis Data Streams

  - フルマネージドなデータストリーミングサービス
  - リアルタイムでのデータ収集、処理、分析をサポート
  - 高いスループットと低レイテンシを提供
  - データのシャーディングとパーティショニングをサポート
  - Kinesis Data Streams と Kinesis Data Firehose の違い
    - Kinesis Data Streams はリアルタイムストリーミングデータの収集と処理に特化。アプリケーションが直接データを読み取り、リアルタイム分析やカスタム処理が可能。
    - Kinesis Data Firehose はデータの収集、変換、保存を簡素化。S3、Redshift、OpenSearch などへのデータ配信に最適化されており、リアルタイム処理よりもバッチ処理に向いている。

- Amazon EMR

  - フルマネージドな Apache Hadoop および Apache Spark クラスターサービス
  - 大規模なデータ処理や分析を簡素化
  - AWS の他のサービスとの統合が容易

- Amazon Rekognition

  - フルマネージドな画像および動画分析サービス
  - 物体検出、顔認識、テキスト検出などの機能を提供
  - 機械学習を活用した高精度な分析

- AWS Data Exchange

  - サードパーティデータの検索・購読・管理を簡素化するサービス
  - AWS Marketplace 経由でデータ製品の売買が可能
  - データ送信者とデータ受信者の間でデータ権限（data grant）を管理

  ### 主要機能

  - **データ受信**: データグラントや Marketplace 購読を一箇所で管理
  - **データ提供**: 配信・権限管理インフラを構築せずにデータ販売が可能
  - **Open Data**: 無料の公開データセット（Open Data on AWS）へのアクセス

  ### 対応データ形式

  - ファイルベース（S3）、API、Amazon Redshift、AWS Lake Formation（プレビュー）
  - 様々なデータフォーマット（CSV、JSON、Parquet 等）をサポート

  ### データグラント

  - データ送信者が作成する交換単位
  - データセット、グラント詳細、受信者アクセス詳細を含む
  - 受信者の AWS アカウント ID と期間を指定してアクセス権を付与

  ### Marketplace 製品

  - プロバイダーが公開する商用データ製品
  - 製品詳細（名前、説明、サンプル、ロゴ）とオファー（価格、条件）を含む
  - AWS のガイドラインとレビューを経て公開カタログに掲載

  ### アクセス方法

  - AWS Data Exchange コンソール、AWS Marketplace、API 経由でアクセス可能
  - データ受信者: コンソールでグラント管理、Marketplace で製品検索・購読
  - データ提供者: コンソールまたは API（Data Exchange API、Marketplace Catalog API）で管理
