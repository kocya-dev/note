## アカウント管理

- AWS Organizations

  - 複数の AWS アカウントを一元管理
  - アカウントの作成、削除、管理を簡素化
  - 組織単位（OU）を使用した階層的な管理

- Cost Usage Report

  - AWS アカウントのコストと使用状況を分析
  - 複数のアカウントのコストを一元管理
  - Athena, Redshift, QuickSight などで分析可能

- AWS Control Tower

  - 複数の AWS アカウントを一元管理
  - ベストプラクティスに基づいたガバナンスを提供
  - セキュリティやコンプライアンスの強化
  - ガードレール
    必須ガードレール（強制）、推奨ガードレール（非強制）の 2 種類がある。
  - アカウントの設定やリソースの使用に関するポリシーを適用
  - セキュリティ、コスト管理、コンプライアンスなどのガイドラインを提供
  - AWS Organizations の SCP（Service Control Policy）や AWS Config ルールを自動的に適用します。
    SCP により、管理アカウントや特定 OU 配下のアカウントで禁止サービスの API 実行をブロックできます。
    - SCP はデフォルトで全てのサービスを許可しますが、明示的に拒否することで制限をかけることができます。
      - デフォルトでは暗黙的に FullAWSAccess が付与される。
      - FullAWSAccess をデタッチ + 特定の Allow リストを作成することで、必要なサービスのみを許可することができます。
      - 明示的な拒否は Allow より優先される。

- AWS Resource Access Manager

  - リソースの共有とアクセス管理を簡素化
  - 複数のアカウント間でのリソース共有をサポート
  - AWS Organizations と統合され、組織全体でのリソース管理が容易

- AWS Config
  - AWS リソースの設定変更を追跡・監査
  - リソースのコンプライアンス状態を評価
  - カスタムルールの作成が可能
  - リソースの変更履歴を保存し、過去の状態に戻すことが可能
  - AWS Config Aggregator
    - 複数アカウントやリージョンの設定データを集約
    - 組織全体のコンプライアンス状態を一元管理

## 管理

- AWS Systems Manager
  - インスタンスの管理と運用
    - リモートアクセスやコマンド実行が可能
  - パッチ管理、構成管理、ログ収集などの機能を提供
  - オートメーション機能を使用して、繰り返しのタスクを自動化
  - オンプレミスサーバーや EC2 インスタンスの一元管理が可能
  - パラメーターストア
    - 構成情報やシークレットの安全な保存
    - アプリケーション設定や環境変数の管理
  - AWS Systems Manager Agent
    - EC2 インスタンスやオンプレミスサーバーにインストールされるエージェント
    - Systems Manager の機能を利用するために必要
