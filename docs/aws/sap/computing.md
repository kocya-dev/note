## compute

- AWS Lambda
  - サーバーレスコンピューティングサービス
  - イベント駆動型のアプリケーション開発をサポート
  - 自動スケーリングと高可用性を提供
  - Lambda@Edge
    - CloudFront エッジロケーションでの Lambda 関数実行
    - レイテンシの低減とグローバルなアプリケーションの最適化
  - Provisioned Concurrency
    - Lambda 関数の起動時に必要なコンカレンシーを事前に確保
    - コールドスタートの遅延を軽減
  - Compute Savings Plans
    - 1 年または 3 年の期間での使用を前提に割引価格で提供
    - 柔軟性が高く、複数のインスタンスタイプやリージョンで利用可能
    - EC2, Lambda, Fargate に対応
- Amazon EC2

  - 仮想サーバーを提供するサービス
  - 多様なインスタンスタイプとサイズを選択可能
  - オートスケーリングやロードバランシングと統合
  - クラスタープレイスメント
    - 複数のインスタンスを同一のアベイラビリティゾーンに配置
    - 高いスループットと低レイテンシを実現
  - パーティションプレイスメント
    - 複数のインスタンスを異なるパーティションに配置
    - 高い可用性と冗長性を提供
  - スプレッドプレイスメント
    - インスタンスを異なるハードウェアに分散配置
    - ハードウェア障害の影響を最小限に抑える
  - EC2 Auto Scaling
    - トラフィックの変動に応じて自動的にインスタンスを追加・削除
    - スケーリングポリシーやスケジュールに基づくスケーリングが可能
  - 購入オプション

    - オンデマンドインスタンス
      - 必要なときに必要なだけ使用
      - 柔軟性が高いがコストは高め
    - リザーブドインスタンス

      - 長期間の使用を前提に割引価格で提供
      - コスト効率が高いが、柔軟性は低い
      - 1 年または 3 年の利用を前提に、EC2 インスタンスの「利用料金割引」を受けられる購入オプション。
      - 実際にインスタンスのキャパシティ（台数分の枠）を確保するものではなく、あくまで「割引権」。
      - 必要なときにオンデマンドインスタンスを起動し、条件が合えば自動的に割引が適用される。
      - 可用性保証はない（混雑時にインスタンスが起動できない場合もある）。

    - Capacity Reservations

      - 特定のインスタンスを予約し、必要なときに確保
      - コスト効率が高く、可用性を向上させる
      - 特定のインスタンスタイプ・AZ で「実際のキャパシティ（枠）」を事前に確保できる。
      - 予約した分は、いつでも確実にインスタンスを起動できる（可用性保証）。
        料金は予約した分のキャパシティに対して発生（割引はなし。RI と組み合わせて割引適用も可能）。

      - スポットインスタンス
        - 余剰のキャパシティを利用して割引価格で提供
        - コスト効率が非常に高いが、可用性は保証されない
      - Savings Plans
        - 1 年または 3 年の期間での使用を前提に割引価格で提供
        - 柔軟性が高く、複数のインスタンスタイプやリージョンで利用可能

  - インスタンスタイプ
    - 汎用（General Purpose：t, m 系）
      バランス型。Web サーバーや開発環境など幅広い用途に最適。
    - バースト可能（Burstable：t 系）
      低コスト・ベースライン＋バースト性能。小規模 Web やテスト環境向け。
    - コンピューティング最適化（Compute Optimized：c 系）
      CPU 性能重視。バッチ処理、Web アプリ、科学計算などに向く。
    - メモリ最適化（Memory Optimized：r, x, z 系）
      大容量メモリ。インメモリ DB、分析、キャッシュ用途に最適。
    - ストレージ最適化（Storage Optimized：i, d, h 系）
      高速・大容量ローカルストレージ。NoSQL、DWH、ビッグデータ処理向け。
    - 高速ネットワーク/高性能（High Performance：p, g, inf 系）
      GPU や推論・機械学習・HPC 用途に特化。
  - EC2 Instance Connect
    - EC2 インスタンスへの SSH 接続を簡素化
    - 一時的な SSH キーを使用してセキュアに接続
    - IAM ポリシーを使用してアクセス制御が可能

- Amazon ECS
  - フルマネージドなコンテナオーケストレーションサービス
  - Docker コンテナのデプロイと管理を簡素化
  - ECS クラスター = 実行環境のグループ
  - ECS タスク = クラスタ上で動くコンテナ実行単位。タスクは必ずクラスターに所属して実行される。
