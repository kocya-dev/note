## バックアップ

- AWS Elastic Disaster Recovery
  - オンプレミスや他のクラウドからの AWS への災害復旧
  - リアルタイムでのデータレプリケーション
  - 数分での復元が可能
  - 秒単位の RPO と分単位の RTO を達成可能（ワークロードに依存）
- AWS Backup
  - AWS サービスのバックアップを一元管理
  - 定期的なバックアップスケジュールの設定
  - バックアップのライフサイクル管理
  - バックアップの暗号化とセキュリティ管理
  - 数時間での復元が可能
  - RPO はバックアップ実施間隔に依存する
- AWS DataSync
  - オンプレミスと AWS 間のデータ転送を簡素化
  - 大量のデータを迅速に移行可能
  - データの整合性を確保
- AWS Snowball
  - データ転送とバックアップのための物理デバイス
  - 大量のデータを迅速に AWS に移行可能
  - セキュリティと耐久性を考慮した設計
- AWS Storage Gateway
  - オンプレミスと AWS のストレージを統合、オンプレミス環境からクラウドのストレージを利用可能にする
  - データのキャッシュやバックアップをサポート
  - ファイルゲートウェイ、ボリュームゲートウェイ、テープゲートウェイを提供
    - ファイルゲートウェイは NFS や SMB プロトコルを使用して、オンプレミスのファイルシステムと AWS S3 を統合
    - ボリュームゲートウェイは iSCSI プロトコルを使用して、オンプレミスのブロックストレージと AWS に接続
    - テープゲートウェイは仮想テープライブラリを提供し、オンプレミスのバックアップソリューションと統合
- AWS Transfer Family
  - SFTP、FTPS、FTP のファイル転送をサポート
  - Amazon S3 や Amazon EFS との統合
  - セキュアなファイル転送を提供
- Amazon Data Lifecycle Manager
  - EBS ボリュームのスナップショット管理を自動化
  - スナップショットの作成、削除、ライフサイクルポリシーの設定が可能
  - コスト削減や運用負荷の軽減に寄与
