## ユーザー管理

- IAM

  - ユーザー、グループ、ロールの管理
  - ポリシーを使用したアクセス制御
  - MFA（多要素認証）のサポート
  - IAM ロール
    - AWS サービスやアプリケーションに一時的なアクセス権を付与
    - クロスアカウントアクセスやフェデレーションをサポート
  - IAM ポリシー
    - JSON 形式でアクセス権限を定義
    - ユーザー、グループ、ロールに適用可能
    - ポリシーの種類
      - 管理ポリシー（AWS 管理ポリシー、カスタマー管理ポリシー）
      - インラインポリシー（特定のユーザー、グループ、ロールに直接埋め込む）
  - IAM ベストプラクティス
    - 最小権限の原則を遵守
    - 定期的なアクセス権限の見直し
    - MFA の有効化
    - ルートアカウントの使用を最小限に抑える
  - 外部 ID
    - クロスアカウントアクセス時のセキュリティ強化
    - 信頼されたエンティティにのみアクセスを許可
    - アカウント間でロールなどを共用する際に、ARN だけでなく特定の ID も使用することで、不正アクセスを防止

- IAM Access Analyzer
  - IAM ポリシーの分析と改善提案
  - リソースベースポリシーのアクセス権限を評価
  - クロスアカウントアクセスの検出
